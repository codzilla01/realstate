# قائمة التسليم للمشتري (Handover)

استخدمها لحظة البيع وتأكّد من كل بند — تمنع 90% من النزاعات بعد التسليم.

## 1) الأصول الرقمية

- [ ] نقل ملكية مستودع Git (أو إنشاء مستودع خاص باسم المشتري ودفع الكود).
- [ ] أرشيف `zip` كامل (بلا `node_modules` و`.env`) كنسخة احتياطية.
- [ ] التأكد من عدم وجود أسرار داخل المستودع: `git log -p | grep -i "password\|secret\|api_key"`.
- [ ] الوثائق: `README.md` + مجلد `docs/` + `CHANGELOG.md` + `NOTICE.md` + `LICENSE`.

## 2) بيانات التشغيل

- [ ] `mysqldump` كامل لقاعدة بيانات المشتري (أو قاعدة تجريبية + بيانات seed).
- [ ] قائمة المتغيرات المطلوبة: `DATABASE_URL`, `JWT_SECRET`, `CORS_ORIGIN`…
- [ ] بيانات الدخول: حساب المدير الجديد (كلمة مرور مؤقتة يُغيَّر فوراً) — لا ترسل كلماتك.
- [ ] أي مفاتيح API (SMS/تخزين) تُنشأ باسم المشتري، ولا تُسلَّم مفاتيحك.

## 3) النشر والتحقق

- [ ] تشغيل `docker compose up --build` بنجاح على بيئة المشتري أو بيئتك.
- [ ] `GET /api/health` يعيد `200` و`database: "up"`.
- [ ] تسجيل دخول ناجح بـ ADMIN، ودخول VIEWER للتأكد من تقييد الكتابة.
- [ ] إنشاء عقار → ظهوره في الموقع العام → إرسال طلب → وصوله في اللوحة.
- [ ] `npm test` يمر (9 اختبارات) و`npm run build` ينجح.

## 4) الحقوق والاتفاقيات

- [ ] توقيع اتفاقية البيع (النطاق، السعر، الدعم، الاسترداد).
- [ ] تسليم `LICENSE` بصيغة تنقل الملكية للمشتري بالاسم والتاريخ.
- [ ] إضافة اسم المشتري في `LICENSE` و`package.json` (اختياري لكن يزيد الاحترافية).
- [ ] توضيح تراخيص المكونات الخارجية (`NOTICE.md`) وأن صور Unsplash روابط خارجية.

## 5) الدومين والاستضافة (إن كانت ضمن الحزمة)

- [ ] نقل الدومين أو تحديث DNS.
- [ ] شهادة SSL سارية (Let's Encrypt + تجديد تلقائي).
- [ ] نسخة احتياطية أولى مجدولة على حساب المشتري.
- [ ] إزالة وصولك إلى الخوادم/الحسابات بعد اكتمال الانتقال.

## 6) فترة الدعم

- [ ] تسجيل تاريخ بداية ونهاية الدعم (مقترح 15–30 يوماً).
- [ ] قناة تواصل واحدة معلنة (بريد/واتساب) وساعات الاستجابة.
- [ ] توثيق أن الميزات الجديدة خارج نطاق الدعم.
- [ ] بعد انتهاء الفترة: أرسل رسالة إغلاق رسمية.

## 7) ملف التسليم النهائي (ZIP)

```
handover/
├── source.zip               # الشيفرة
├── docs/                    # نسخة من الوثائق
├── database-backup.sql      # نسخة البيانات (إن وُجدت)
├── LICENSE-مُوقَّعة.pdf
├── delivery-note.txt        # الروابط، الحسابات، المتغيرات، تاريخ الدعم
└── credentials.enc          # كلمات المرور المؤقتة (مشفّرة)
```
