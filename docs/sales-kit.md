## 1) العرض في 30 ثانية

**منصة عقارية عربية جاهزة للسوق** — موقع عام أنيق للعقارات (بيع/إيجار) +
لوحة تحكم كاملة تدير العقارات والعملاء والعقود والطلبات والتقارير، بصلاحيات
أربعة أدوار، أمان مطبَّق (JWT، rate limiting، OTP)، ونشر بأمر واحد عبر Docker.
مبنية بـ React 19 + Express + Prisma/MySQL، كود نظيف وموثّق بالكامل، جاهزة
للتخصيص والبيع كخدمة أو تسليمها لمكتب عقاري.

**الجملة التسويقية:**
> «موقع عقارات + CRM جاهز للعمل — بدل 4–6 أسابيع تطوير، ابدأ اليوم.»

## 4) نقاط البيع (استخدمها في الإعلان)

1. **عربي أولاً وRTL بالكامل** — أغلب القوالب الأجنبية تحتاج إعادة بناء للاتجاه.
2. **CRM وليس موقع عرض فقط** — عملاء، عقود، عمولات، طلبات، تقارير.
3. **أمان جاهز للإنتاج** — ليس مجرد CRUD: حدود طلبات، OTP بحد محاولات،
   رفع صور بتحقق من بصمة الملف، وصلاحيات مفروضة من الخادم.
4. **يعمل فوراً** — `npm run demo` يعرض كل شيء دون قاعدة بيانات (مثالي للعرض).
5. **نشر بأمر واحد** — Docker Compose + nginx + healthcheck.
6. **كود مقروء وقابل للتخصيص** — بلا تعقيد أو حزم زائدة، مع وثائق عربية.
7. **جاهز لإعادة العلامة التجارية (White-label)** — اسم المكتب في 3 مواضع فقط.

## 6) نموذج التسعير المقترح

| الحزمة | المحتوى | السعر الاسترشادي |
|---|---|---|
| **أ) الكود فقط (Basic)** | المستودع + الوثائق، دون تخصيص أو نشر | 9,000–15,000 جنيه / 250–450 دولار |
| **ب) جاهز للنشر (Standard)** | + نشر على استضافة العميل + تغيير الهوية + بياناته الحقيقية | 18,000–30,000 جنيه / 500–900 دولار |
| **ج) أعمال كاملة (Premium)** | + ربط SMS + تخزين سحابي للصور (S3) + لقطات شاشة + 30 يوم دعم | 35,000–55,000 جنيه / 900–1,500 دولار |
| **د) SaaS متعدد المكاتب** | Multi-tenancy + باقات اشتراك + لوحة مشرف عام | حسب الاتفاق (مشروع منفصل) |

**إضافات مضمونة الطلب:** رفع الصور (1,500–3,000 ج)، SMS (1,500–3,000 ج)،
تصدير Excel (1,000–2,000 ج)، نسخة إنجليزية (3,000–6,000 ج)، لقطات + فيديو (1,000–2,000 ج).

> هذه أرقام استرشادية لوضع السوق المصري. للمملكة/الخليج اضربها 2–3 مرات.
> لا تبِع بسعر يقل عن تكلفة 5 أيام عمل — وإلا فقدت مصداقية المنتج.

## 8) أسئلة يطرحها المشتري (وأجوبتها)

**هل يعمل مباشرة؟** نعم، وبـ`npm run demo` تجربته دون أي إعداد.
**هل الكود أصلي؟** نعم، مبني لهذا المشروع، والمكونات مفتوحة المصدر مذكورة في `NOTICE.md`.
**هل يمكن تغيير الألوان/الاسم؟** نعم: `tailwind.config.js` + موضعان للاسم في الواجهة.
**هل يدعم أكثر من مكتب؟** النسخة الحالية لمكتب واحد. للتحول إلى SaaS متعدد
المكاتب يوجد مخطط تنفيذي جاهز (15–21 يوماً) في `docs/multi-tenant-plan.md` —
يمكن بيعه كمشروع منفصل أو كاشتراك شهري إن استضفته أنت.
**هل يوجد دعم بعد البيع؟** حدده في عرضك (مقترح: 15–30 يوم إصلاح أخطاء، لا ميزات جديدة).
**هل يمكن إعادة البيع؟** حسب رخصتك (الافتراضي في `LICENSE`: نقل الملكية مرة واحدة).
**ما الذي يحتاج استضافة؟** Node.js + MySQL + دومين — أي VPS بـ 2GB RAM يكفي.

## 9) شروط البيع ونقل الملكية (مقترح)

1. **الملكية:** تنتقل كاملة للمشتري بعد السداد الكامل.
2. **التسليم:** مستودع Git خاص + أرشيف ZIP + الوثائق.
3. **السرية:** لا تُنشر الشيفرة علناً قبل إتمام البيع.
4. **الاسترداد:** غير قابل للاسترداد بعد تسليم الشيفرة (أو 3 أيام فحص فني فقط).
5. **الدعم:** 15–30 يوم إصلاح أخطاء، الميزات الجديدة بعرض منفصل.
6. **الاستخدام:** استخدام غير محدود في مشاريع المشتري، ونقل واحد لطرف ثالث.
7. **الإفصاح:** اذكر أن الصور التجريبية روابط Unsplash وأن SMS غير مربوط.

## 9.5) خياران للبيع: مكتب واحد أم SaaS؟

| الجهد الإضافي | لا شيء | 15–21 يوم عمل (المخطط جاهز) |
| نصيحة | ابدأ ببيعها الآن لتغطية تكلفة التطوير | لا تبدأها قبل وجود عميل دافع |

## 10) قبل أن تنشر العرض — 5 خطوات سريعة

1. شغّل `npm run demo` ثم `node scripts/screenshots.mjs` لتوليد 8 لقطات جاهزة
   تلقائياً في `docs/screenshots/` (الرئيسية، العقارات، التفاصيل، الدخول، اللوحة، العقارات، العقود، التقارير).
2. أنشئ حساب مدير باسمك وغيّر كلمة المرور التجريبية.
3. أضف 8–10 عقارات وهمية بصور جيدة (أو استخدم seed الحالي).
4. انشر نسخة تجريبية على Vercel/Railway وضع رابطها في الإعلان.
5. اطبع [one-pager.html](one-pager.html) إلى PDF، وأرفق به [sales-agreement-template.md](sales-agreement-template.md)
   و[handover-checklist.md](handover-checklist.md) لمن يسأل.
