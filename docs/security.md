# الأمان

## ما هو مطبَّق فعلياً

### المصادقة والجلسات
- كلمات المرور: `bcrypt` بـ 12 rounds، ولا تُعاد أبداً في أي استجابة.
- JWT موقَّع بـ HS256، مدة افتراضية 7 أيام، ويُرفض إذا تغيّر المفتاح.
- **إلزام `JWT_SECRET` قوي في الإنتاج**: التطبيق يفشل في الإقلاع إذا كان غائباً
  أو أقصر من 32 حرفاً (`src/lib/config.js`).
- التسجيل العام مغلق افتراضياً؛ حتى عند تفعيله لا يمكن إنشاء `ADMIN`.
- إنشاء الحسابات وتغيير الأدوار في يد المدير فقط (`/api/users`).
- المدير لا يستطيع تعطيل نفسه أو حذف حسابه أو تخفيض دوره.

### OTP
- صلاحية 5 دقائق (قابلة للضبط)، رمز واحد فعّال في كل مرة (الطلب الجديد يلغي القديم).
- أقصى 5 محاولات لكل رمز (`OTP_MAX_ATTEMPTS`) مع عدّاد في قاعدة البيانات.
- مقارنة الرمز بـ `timingSafeEqual`، والرمز لا يُعاد في الاستجابة في الإنتاج.
- لا يكشف وجود الرقم من عدمه (نفس الرسالة دائماً).

### منع الإساءة
| المسار | الحد |
|---|---|
| كل الـ API | 300 طلب/دقيقة/IP |
| تسجيل الدخول | 10 محاولات/15 دقيقة لكل (IP+هاتف) |
| طلب OTP | 5/10 دقائق |
| التحقق من OTP | 20/10 دقائق |
| نموذج الطلبات العام | 10/10 دقائق |
| إنشاء حساب عام | 10/15 دقيقة |

> الحدود في الذاكرة (مناسبة لخادم واحد). عند التوسع لعدة نسخ، استبدل
> `src/middleware/rateLimit.js` بمخزن Redis مع الحفاظ على نفس الواجهة.

### رفع الملفات
- الرفع يتطلب `ADMIN|MANAGER|AGENT`، وحد 60 عملية / 10 دقائق.
- نوع الصورة يُكتشف من **بصمة الملف** (magic bytes) وليس من `Content-Type`
  أو الامتداد، فلا يمكن رفع سكربت متنكّر بصورة.
- الحد الأقصى 5MB (`MAX_UPLOAD_MB`)، والملفات تُحفظ بأسماء UUID عشوائية.
- التقديم يتم عبر مسار مخصص يتحقق من نمط الاسم ويرسل
  `X-Content-Type-Options: nosniff` + `Content-Disposition: inline`،
  بحيث لا يجري تجاوز المسار وسكربتات HTML المرفوعة لا تُنفَّذ.
- الملفات غير الصالحة لا تُكتب على القرص (التحقق قبل الحفظ).

### الصلاحيات وحدود البيانات
- كل مسار محمي يمر بـ `requireAuth` + `requireRole` على مستوى الـ route.
- `VIEWER` للقراءة فقط، وواجهة الاستخدام تخفي أزرار الكتابة.
- الإشعارات مقيّدة بمالكها (لا يمكن تعليم إشعار مستخدم آخر).
- المسودات (DRAFT) مستثناة من القوائم العامة، وصفحة العقار تعيد 404 للزوار.

### الشبكة والمدخلات
- ترويسات أمان: `nosniff`, `X-Frame-Options: DENY` للـ API, `Referrer-Policy`,
  `Permissions-Policy`, وHSTS في الإنتاج.
- CORS بقائمة أصول (بدل `*`) مع `trust proxy` لقراءة IP الحقيقي خلف nginx.
- تقييد حجم جسم الطلب إلى 1MB، والتحقق من كل حقل عبر Zod.
- معالج أخطاء موحّد: تفاصيل الاستثناء لا تُرسل في الإنتاج، وأخطاء Prisma
  (تكرار/مرجع مفقود) تتحول إلى 409/404 مفهومة.
- `x-powered-by` معطّل، وأخطاء async تُلتقط بفضل `express-async-errors`.

## قبل الإطلاق — قائمة إلزامية

- [ ] غيّر كلمة مرور المدير التجريبية واحذف الحسابات التجريبية.
- [ ] `CORS_ORIGIN` = الدومين فقط؛ لا `*` في الإنتاج.
- [ ] `EXPOSE_DEV_OTP=false`, `ALLOW_PUBLIC_REGISTRATION=false`.
- [ ] HTTPS + HSTS + إعادة توجيه إجباري من HTTP.
- [ ] نسخ احتياطي مشفّر ومجدول، ومختبَر استعادته.
- [ ] ربط مزود SMS حقيقي قبل الاعتماد على الدخول بـ OTP.
- [ ] إضافة CSP على مستوى nginx (مثال أدناه).
- [ ] مراجعة سجلات الخادم أسبوعياً أول شهر.

## تحسينات موصى بها (غير مطبقة بعد)

1. **Refresh tokens + قائمة إلغاء** لتقصير عمر الوصول (حالياً 7 أيام).
2. **2FA للمدير** (TOTP) — حماية أقوى من OTP للوحة.
3. **تخزين Rate limit في Redis** عند تعدد النسخ.
4. **سجل تدقيق (Audit log)** لكل عملية كتابة.
5. **رفع الصور مع تحقق من نوع الملف وحجمه** عند الانتقال من الروابط للتخزين السحابي.
6. **سياسة كلمات مرور** (طول/تعقيد/منع الشائعة) — حالياً 8 أحرف كحد أدنى.

### مثال CSP (nginx)

```nginx
add_header Content-Security-Policy "default-src 'self'; img-src 'self' data: https:; style-src 'self' 'unsafe-inline' https://fonts.googleapis.com; font-src 'self' https://fonts.gstatic.com; script-src 'self'; connect-src 'self'; frame-ancestors 'none'" always;
```

قد تحتاج تعديل `img-src` حسب مصدر الصور الذي تختاره.
