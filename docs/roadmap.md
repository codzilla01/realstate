## أفكار تحسين تقنية (لا تُرى لكن تُحسّ)

- تقسيم حزمة الواجهة (code splitting) — الحزمة الحالية ~860KB قبل الضغط.
- تحويل `price` Decimal إلى `number` في طبقة الـ API لتوافق أبسط مع التكاملات.
- Dexie/React Query للتخزين المؤقت وتقليل طلبات الشبكة في اللوحة.
- ضغط الصور تلقائياً عند الرفع + `srcset` للعرض المتجاوب.
- Rate limit في Redis عند تعدد النسخ.
- فحص أمني دوري (`npm audit`) في CI + تجديد الحزم كل ربع سنة.

## كيف تسعّر الإضافة

معادلة بسيطة: **(أيام × سعر اليوم) + 20% مخاطرة + قيمة تجارية للعميل**.
الإضافات من نوع 1 و2 و5 تُطلب دائماً تقريباً — اذكرها كباقة جاهزة في العرض.
