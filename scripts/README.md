# سكربتات مساعدة

## `screenshots.mjs` — لقطات الشاشة التسويقية

```bash
# مرة واحدة
npm i -D playwright
npx playwright install chromium

# في طرفية أولى: تشغيل النسخة التجريبية
npm run demo

# في طرفية ثانية
node scripts/screenshots.mjs
```

| الخيار | الافتراضي | الوصف |
|---|---|---|
| `--url` | `http://localhost:5173` | عنوان الموقع |
| `--out` | `docs/screenshots` | مجلد الحفظ |
| `DEMO_PHONE` | `201000000001` | حساب الدخول للوحة |
| `DEMO_PASSWORD` | `admin1234` | كلمة المرور |

ينتج مقاس 1440×900: الرئيسية، العقارات، تفاصيل عقار، دخول اللوحة، لوحة المعلومات،
العقارات، العقود، التقارير — جاهزة لصفحة البيع و`docs/one-pager.html`.

> لقطات الشاشة تُنتَج بأسماء مرقّمة لتسهيل ترتيبها. أعد التشغيل بعد أي تغيير في
> الواجهة أو البيانات التجريبية.
