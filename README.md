# نظام إدارة العقارات — Real Estate MVP

منصة عقارية متكاملة (بيع/إيجار) مع موقع عام بالعربية (واجهة داكنة/ذهبية) ولوحة
تحكم إدارية كاملة.

## البنية التقنية (Stack)

- **Backend:** Node.js + Express + Prisma ORM + MySQL + JWT
- **Frontend:** React (Vite) + Tailwind CSS + React Router + Leaflet (خرائط) + Recharts (تقارير)
- **المصادقة:** رقم الهاتف + كلمة مرور، أو رقم هاتف + رمز تحقق (OTP)

## هيكل المشروع

```
realestate-mvp/
  backend/     # Express API + Prisma schema
  frontend/    # React admin + public site
```

## 1) تشغيل الـ Backend

### المتطلبات
- Node.js 18+
- خادم MySQL (محلي أو سحابي، مثل PlanetScale/RDS/XAMPP/etc.)

### الخطوات

```bash
cd backend
cp .env.example .env
```

عدّل ملف `.env` وضع بيانات اتصال MySQL الخاصة بك:

```
DATABASE_URL="mysql://USER:PASSWORD@HOST:PORT/DATABASE"
JWT_SECRET="ضع نصاً عشوائياً طويلاً هنا"
```

ثم:

```bash
npm install
npm run prisma:generate
npm run prisma:migrate      # ينشئ الجداول في قاعدة البيانات
npm run prisma:seed         # يضيف بيانات تجريبية + حساب مدير
npm run dev                 # يشغل السيرفر على http://localhost:4000
```

> **ملاحظة:** بيئة البناء التي أنشأت هذا الكود لا تملك اتصال إنترنت لتحميل
> محرك Prisma الثنائي (بسبب سياسة الشبكة في بيئة التطوير السحابية)، لذلك لم
> يتم تشغيل `prisma migrate` فعلياً هنا. تأكدت من صحة الشيفرة عبر فحص syntax
> لكل ملف. على جهازك (باتصال إنترنت طبيعي) ستعمل هذه الأوامر مباشرة.

### حسابات الدخول التجريبية (بعد تشغيل seed)

| الدور  | رقم الهاتف     | كلمة المرور  |
|--------|-----------------|--------------|
| مدير   | `201000000001`  | `admin1234`  |
| وكيل   | `201000000002`  | `agent1234`  |

### تسجيل الدخول بـ OTP

في وضع التطوير، عند طلب OTP (`POST /api/auth/otp/request`) سيتم طباعة الرمز
في الـ console الخاص بالسيرفر، وسيُعاد أيضاً ضمن الاستجابة (`devOnlyOtp`)
لتسهيل الاختبار. لربط مزود SMS حقيقي (مثل Twilio) لاحقاً، عدّل الجزء المعلّق
في `backend/src/routes/auth.routes.js`.

## 2) تشغيل الـ Frontend

```bash
cd frontend
cp .env.example .env
npm install
npm run dev          # يفتح على http://localhost:5173
```

تأكد أن `VITE_API_URL` في `.env` يشير لعنوان الـ backend الصحيح
(افتراضياً `http://localhost:4000/api`).

- الموقع العام: `http://localhost:5173/`
- دخول الإدارة: `http://localhost:5173/admin/login`

## 3) الميزات المُنفّذة (MVP)

- تسجيل دخول بالهاتف + كلمة مرور، أو هاتف + OTP.
- صلاحيات أدوار: مدير (ADMIN)، مشرف (MANAGER)، وكيل (AGENT)، مشاهد (VIEWER).
- CRUD كامل للعقارات (بيع/إيجار، نوع، سعر، صور، موقع جغرافي).
- بحث وتصفية العقارات (نوع، غرض، سعر، مدينة، كلمة بحث).
- صفحة تفاصيل العقار مع خريطة (Leaflet/OpenStreetMap) ونموذج طلب معاينة.
- إدارة العملاء (CRM بسيط).
- إدارة العقود (بيع/إيجار) مع نسبة عمولة ومبلغ وحالة.
- إدارة طلبات العملاء (Inquiries) مع تحديث الحالة.
- إشعارات داخلية للمدراء عند وصول طلب جديد.
- إدارة المستخدمين (مدير فقط): إنشاء/تعطيل/تفعيل.
- لوحة تقارير: إحصائيات عامة + رسوم بيانية (توزيع العقارات).
- تصميم عربي (RTL) بالكامل، ثيم داكن/ذهبي.

## 4) ما لم يُنفّذ بعد (يحتاج وقتاً إضافياً)

الطلب الأصلي طلب "تسليم خلال ساعة" — هذا غير واقعي لنظام كامل بهذا الحجم.
ما تم تسليمه هو MVP وظيفي بالكامل من ناحية الكود، لكن التالي يحتاج جلسات
إضافية إذا رغبت:

- رفع صور فعلي (حالياً الصور تُدخل كروابط URL يدوياً؛ يمكن ربطها لاحقاً
  بخدمة تخزين مثل S3/Cloudinary).
- إرسال OTP عبر SMS حقيقي (حالياً محاكاة/console log فقط).
- اختبارات آلية (unit/integration tests).
- نشر (Deployment) فعلي على خادم/Vercel/Railway.
- ترجمة إنجليزية كاملة للواجهة العامة (البنية تدعمها لكن المحتوى بالعربي حالياً).
