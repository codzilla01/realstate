# المكتب العقاري · Al Maktab

واجهة عربية للعقارات ولوحة إدارة متصلة بها عبر خادم Node.js وقاعدة SQLite. يرسل الخادم رموز تسجيل الدخول عبر خدمة SMTP.

## التشغيل

يتطلب **Node.js 22.13 أو أحدث**.

```sh
npm ci
cp .env.example .env
# أدخل ADMIN_EMAIL وإعدادات SMTP داخل .env لتفعيل لوحة الإدارة.
npm start
npm test
```

- `/` موقع الزوار: البحث، تصفية العقارات وترتيبها، المحفوظات المحلية، روابط العقارات، وطلبات المعاينة أو الاستشارة.
- `/admin` لوحة الإدارة: المسودات والمعاينة الخاصة والنشر، إدارة التوفر والعقارات المميزة، متابعة الطلبات والمواعيد، تصدير النتائج، وتحرير محتوى الواجهة.
## تفعيل الدخول بالبريد

1. عيّن `ADMIN_EMAIL` إلى البريد الوحيد المخوّل بإدارة الموقع. استخدم صندوق بريد خاصًا بالإدارة ومحمياً بالمصادقة متعددة العوامل.
2. عيّن `SMTP_HOST` و`SMTP_PORT` و`SMTP_FROM` حسب مزود الإرسال. إذا تطلّب المصادقة، اضبط `SMTP_USER` و`SMTP_PASSWORD` معًا في بيئة الخادم. المنفذ `587` يتطلب STARTTLS، والمنفذ `465` يستخدم TLS من بداية الاتصال. استخدم عنوان إرسال معتمدًا لدى المزود.
3. أعد تشغيل الخادم، وافتح `/admin` في المتصفح مباشرة، وأدخل البريد ثم الرمز المرسل إليه. الرمز صالح لخمس دقائق، ويُستخدم مرة واحدة في المتصفح الذي طلبه. بعد خمس محاولات خاطئة يلزم طلب رمز جديد. يمكن إعادة الطلب بعد دقيقة، وقد تطول المهلة عند تكرار الطلبات. إذا لم يصل البريد، راجع الرسائل غير المرغوب فيها وسجل مزود الإرسال.

لا توجد كلمة مرور احتياطية. يظل الموقع العام متاحًا في وضع التطوير دون إعدادات البريد، لكن لا يمكن تسجيل الدخول. عند الترقية من النسخة القديمة احذف `ADMIN_PASSWORD`، وسيحتاج المشرف إلى تسجيل الدخول مرة أخرى. تغيير البريد الإداري يلغي الجلسات السابقة أيضًا. الاختبارات تستخدم مرسلًا محليًا بديلًا؛ يلزم اختبار الإرسال من بيئة الاستضافة بعد إعداد SMTP.

## البيانات والنشر

- الموقع يحتاج إلى استضافة تدعم Node.js؛ استضافة الملفات الثابتة وحدها لا تشغّل خدمات العقارات والطلبات.
- شغّل بالخيار `NODE_ENV=production` خلف وكيل HTTPS يحافظ على ترويسة `Host`. في هذا الوضع تكون إعدادات البريد والإرسال إلزامية ويصبح ملف تعريف ارتباط الإدارة `Secure` تلقائيًا.
- شغّل نسخة خادم واحدة؛ تُحفظ تحديات الدخول المؤقتة في ذاكرة الخادم ولا تُنقل بين النسخ أو تبقى بعد إعادة التشغيل.
- `DATABASE_PATH` يحدّد مسار قاعدة البيانات؛ المسار الافتراضي `data/almaktab.sqlite`. اربط المسار بوحدة تخزين دائمة واحتفظ بنسخ احتياطية آمنة باستخدام أدوات النسخ الاحتياطي لـ SQLite. هذه القاعدة تتضمّن بيانات تواصل العملاء؛ لا تجعلها متاحة عبر الويب أو Git.
- شغّل على قاعدة جديدة مع `SEED_DEMO=false` للبيانات الحقيقية. إيقاف البذر لا يحذف العقارات النموذجية الموجودة سابقًا؛ يمكن إلغاء نشرها من اللوحة. الصور النموذجية توضيحية ومولّدة وليست توثيقًا لعقارات معروضة للبيع.
- بيانات `localStorage` الخاصة بالنسخة السابقة لا تُرحّل تلقائيًا، لأنها محفوظة في متصفح كل مستخدم. أدخل أي سجلات مطلوبة في المنظومة الجديدة بعد مراجعتها.
- تحديد موعد في اللوحة يحفظه بتوقيت الإمارات. لا تُرسل إشعارات المعاينة إلى العميل تلقائيًا؛ يمكن التواصل معه باستخدام بيانات الطلب.
- لوحة الإدارة في هذا الإصدار تدعم بريدًا إداريًا واحدًا، وليس حسابات فريق متعددة. طلبات العملاء متاحة في لوحة الإدارة ويمكن تحديث قائمتها من داخل اللوحة.
- لا تستخدم أي بيانات اعتماد كانت مضمّنة في النسخة السابقة. ألغِ رمز بوت Telegram القديم أو دوّره من الجهة المسؤولة؛ حذفه من الشفرة الحالية لا يمحوه من سجل Git.
